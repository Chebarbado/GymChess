# GymChess
Pull-up ladder with a chess clock: each player has their own timer, and turns are passed in turns.
2–4 players on one device. The first player to complete the ladder and save the most time wins. Anyone who runs out the clock is eliminated.

| Setting | Options |
| --- | --- |
| Exercise | Pull-ups or dips |
| Ladder height | Max reps (e.g. 10) |
| Type | Fast `1-2-3…` · Slow `1-1-2-2…` · Only up `1…N` · Up and down `1…N…1` |
| Time | Minutes per player |
| Players | Up to 4 players|

## Guide
1. **Setup** — set exercise, height, type, time, player count  
2. **Players** — set names  
3. **Game** — clocks, current reps, pass turn / pause / forfeit  
4. **Results** — winner and standings  
5. **History** — past games (up to 50)
